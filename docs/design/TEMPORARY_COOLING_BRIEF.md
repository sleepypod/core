# Temporary cooling surface brief

Mode: Operate. Extend the existing Tonight interface and native equivalents.
Preserve the [product contract](../../PRODUCT.md), established type, semantic
colors, navigation and physical-side naming. No replacement visual system.

The nighttime task is to request a modest, temporary change without opening a
schedule editor. Show “I’m too hot” beside the current plan, followed by an inline
review naming the physical zone, current/requested target and latest return time.
Make the active request and cancellation visible in the same place. Use ordinary
buttons, divided space and brief text; do not add decorative scores or a modal.

The request affects only its explicit zone, even when normal schedules mirror.
Acknowledge the Pod reply without claiming felt cooling. A lost reply offers a
read of the same receipt, never a retry or an offline queue. Expired observations
withdraw proposals. A side change retires the preview. The existing power-off
control remains the primary Stop action.

Verify actual narrow/wide and phone/tablet renders, large text, keyboard targets,
ready/review/active/stale/unconfirmed states, requested units and no horizontal
overflow. The reviewed return time may shorten for wake warming; it cannot move
later during submission. Physical qualification is distinct from UI tests.
