# Personal quiet time

Mode: Operate. Extend the established personal browser workspace without replacing
its typography, neutral surfaces, blue action controls or light/dark appearances.

Either prepared person can request quiet for 30 minutes, one, two or eight hours.
Each edits only their own request. The section follows Tonight and distinguishes
their saved end from the shared end, with explicit refresh and uncertain-result
recovery. A request does not identify a sleeper from occupancy or change a routine.

Use one restrained section with a clear state, a labeled native duration select,
one primary save action and a separate end-my-request action. Preserve readable
phone/tablet layouts, large text and visible keyboard focus. An unavailable state
cannot appear as an inactive request. A receipt is not physical confirmation.

The disclosed scope names the currently connected base and Home Assistant routines,
the short publication delay, existing-movement Stop, and the still-unconnected
audio/other automations. Account changes, stale reads and backgrounding withdraw
live state. Writes are explicit; recovery and periodic refresh never replay them.

Quality bar: someone should distinguish their request from a partner's at a glance,
end only their own request without a modal, and recover a lost response without
guessing whether it saved. At 390px and enlarged text, every action must remain
reachable without horizontal scrolling. No new decorative assets or visual world.

Acceptance: model/transport tests, browser behavior and rendered light/dark captures,
independent finish review, production bundle isolation, and real HTTP contract tests.
These are software checks; native parity and installed hardware acceptance remain.
